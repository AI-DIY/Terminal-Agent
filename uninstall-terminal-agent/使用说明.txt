Terminal-Agent 卸载残留清理工具

适用场景
当 Windows 的“已安装的应用”或“控制面板 - 程序和功能”中出现无法卸载、重复或残留的 Terminal-Agent 条目时，可使用此工具清理这些卸载入口。

使用方法
1. 完整解压下载的 ZIP 文件。
2. 双击“清理 Terminal-Agent 卸载残留.cmd”。
3. Windows 请求管理员权限时，选择“是”。
4. 工具会列出所有名称包含 Terminal-Agent 的卸载条目。
5. 只有输入大写 Y 并按 Enter，工具才会继续删除。

重要说明
- 工具不会卸载 Terminal-Agent 程序。
- 工具不会删除安装目录、用户配置、会话、日志或 AccessClient 的 InstallPath 注册信息。
- 工具会删除所有列出的 Terminal-Agent 卸载入口，包括仍然有效的当前安装入口。
- 每个条目删除前都会先导出 .reg 备份。备份目录会显示在结果窗口中。
- 若需要恢复卸载入口，可双击对应的 .reg 备份文件并确认导入。
- 删除有效卸载入口后，如需正常卸载 Terminal-Agent，请重新运行安装包修复安装，再通过 Windows 卸载。
